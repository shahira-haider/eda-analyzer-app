# 📊 EDA Analyzer App

An interactive Streamlit web application for Exploratory Data Analysis (EDA). Upload any CSV dataset and instantly explore statistics, missing values, correlations, and data quality insights.

## ✨ Features

* Upload CSV datasets
* Dataset overview (rows & columns)
* Statistical summary
* Missing value analysis
* Correlation matrix
* Data quality report
* Interactive visualizations

## 🛠️ Tech Stack

* Python
* Streamlit
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
